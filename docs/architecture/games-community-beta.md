# 游艺厅与社区公开测试策划

更新：2026-10-14。沿用原任务书的纯虚拟积分、无充值/提现/兑换/转让规则。邮箱账户、签到、游戏和预测共享同一个服务器钱包。小游戏可能增发或销毁积分，与逐集预测彩池独立，不把小游戏描述为稳定赚取积分的渠道。

## 本次开放范围

1. 夜城轮盘：欧式单零轮盘，支持单号、红黑、单双、大小。
2. 义体老虎机：三独立转轴，四个获奖符号及空白。
3. 测试预测场：与正式第 1 集分开，开放 30 天，订单可随时退回原积分；没有剧情判定或自动死亡结算。封盘只停止新增订单，退款仍然可用。测试订单、流水保留。
4. 用户名：首次注册设置，2–20 位文字、数字、空格、下划线或短横线。NFKC 规范化，大小写不敏感唯一；不能使用管理员、官方、系统等保留名称。老用户点右上角头像修改。重复登录不覆盖已有名字。
5. 公共留言板与各角色留言板：按「用户名：内容」显示，每条 1–500 字符，10 秒发送间隔；展示最近 100 条，可刷新。作者可撤下，其他登录用户可举报；3 位不同用户举报后自动隐藏待核查。管理后台审核界面仍属后续范围，举报记录保存在数据库。

## 轮盘奖表

服务器从 0–36 等概率抽取一个数字，每种结果概率 1/37。标准红色为 1、3、5、7、9、12、14、16、18、19、21、23、25、27、30、32、34、36；其他非零为黑色。

| 选择 | 命中概率 | 含本金总返还 | 净赢赔率 |
| --- | --- | --- | --- |
| 单号（含 0） | 1/37 | 投入 ×36 | 35:1 |
| 红/黑 | 18/37 | 投入 ×2 | 1:1 |
| 单/双 | 18/37 | 投入 ×2 | 1:1 |
| 小 1–18 / 大 19–36 | 18/37 | 投入 ×2 | 1:1 |

0 不计为双数、小数或红黑命中。全部已开放投注的理论返还率为 36/37，约 97.30%。分注、街注、角注、六线、列和十二数保留在下一阶段，不在当前测试版中假装可玩。

## 老虎机奖表与权重

每轴有 61 个等概率虚拟停位：骷髅、金币、芯片、义眼各 10 个，空白 21 个。三轴独立，先判断三个相同，再判断恰好两个相同，奖项互斥，空白不获奖。

| 奖项 | 含本金总返还 | 净赢赔率 |
| --- | --- | --- |
| 三骷髅 | 投入 ×51 | 50:1 |
| 三金币 | 投入 ×21 | 20:1 |
| 三芯片 | 投入 ×11 | 10:1 |
| 三义眼 | 投入 ×6 | 5:1 |
| 恰好两个相同的非空白符号 | 投入 ×2 | 1:1 |
| 其余组合 | 0 | — |

原策划未确定符号权重。本版加入空白停位以满足其 90%–95% 目标：

- 三同贡献：(51+21+11+6) ×10³ = 89000。
- 两同贡献：4 ×3 ×10² ×51 ×2 = 122400。
- 理论返还率：(89000+122400) /61³ = 211400/226981 ≈ 93.14%。

测试穷举所有 226981 个组合，核对总返还，不以少量随机试玩估计概率。理论返还率是长期数学期望，不保证个人收益。

## 页面与操作

主页增加「游艺厅」和「留言板」导航。两款机器分别进入弹窗，每局默认投入 5，支持 1–50 整数积分，3 秒操作间隔，无自动连玩。单次确认后显示投入、含本金总返还、净增减和余额。概率奖表可在机器内展开，最近 20 局可随时查询。

动效采用短时 RGB 色偏和局部文字错位；按钮悬停只播放一次故障脉冲，标题每 7 秒出现一次短促错位，不做全屏闪白。暂停动效和系统减少动态效果设置都可关闭。

## 结果、账本和异常

- 结果仅由服务端加密随机源生成，拒绝采样消除取模偏差，前端不提交中奖结果。
- 每局 ID、投入、返还、原始结果与时间持久保存。扣除和返奖分别写入不可改写的账本，整笔事务失败则全部回滚。
- 幂等键按用户隔离且绑定路径与请求内容。断网后用原键恢复原结果，不能重新抽奖；浏览器保存未确认请求，刷新后进入任一机器即恢复该局。
- 预测扣款、退款、留言限流和游戏限流在数据库事务中约束，防止并发绕过。
- 测试预测退款只允许订单本人操作，不重复发积分，退款后从彩池和角色赔率中排除该订单。
- 公开留言按纯文本转义呈现，作者名来自服务器，不接受前端伪造作者或角色权限。
